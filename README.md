# Asheesh Kumar | Personal Portfolio

A colorful, responsive personal portfolio website that showcases my skills, projects, coding profiles, education and a working contact form.

**Live Demo:** asheeshkumar.netlify.app



---

## About

I am a B.Tech CSE (Data Science) student at Maharana Pratap Engineering College, Kanpur (AKTU), graduating in 2027, with a strong interest in data structures, algorithms and software development. This portfolio brings my work together in one place.

## Features

- Responsive layout that works on mobile, tablet and desktop
- Typewriter-style role text in the hero section
- Coding achievements section (LeetCode, HackerRank, GeeksforGeeks)
- Skills, certifications and education sections
- Projects showcase with tech tags and GitHub links
- Scroll-reveal animations and scrolling skill chips
- Working contact form powered by Web3Forms (messages go straight to my inbox)

## Run Locally

1. Clone the repository:
   ```bash
   git clone https://github.com/asheeshkumar7521-lab/portfolio-website.git
   ```
2. Open the folder:
   ```bash
   cd portfolio-website
   ```
3. Open `index.html` in your browser (or use the VS Code Live Server extension).

## Contact Form Setup

The form uses [Web3Forms](https://web3forms.com). To use your own copy:

1. Get a free access key from web3forms.com (it is sent to your email).
2. In `index.html`, replace the value of the hidden `access_key` input with your key.
